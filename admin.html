Configuración de GitHub

Para guardar permisos en el repositorio necesitas un token de GitHub con permisos de escritura. Se guarda solo en este navegador, no se sube al repositorio.

  1. Ve a github.com/settings/tokens
  2. Genera un Personal access token (classic)
  3. Marca el permiso repo
  4. Copia el token y pégalo aquí abajo
